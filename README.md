# The Funniest Office Joke, Judged Head to Head

make.fun entry: a program that writes one original one-line joke about
office life to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

Pure standard library, no network. The entry is a single line of
1–200 characters, no trailing newline.

## The joke

> I asked IT to fix the printer, and now the printer has a ticket, a queue,
> a maintenance window, and a better work-life balance than I do.
